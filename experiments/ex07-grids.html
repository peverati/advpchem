Experiment 7: Integration Grids

The argon dimer, and wiggles that shouldn’t be there

How the numerical integration grid affects DFT results, studied on the Ar2 dissociation curve.

At a glance. 31 Ar₂ distances plus the Ar atom, five functionals, three grids, all with def2-TZVP: 480 jobs. SG-1 jobs take seconds, SG-2 and SG-3 jobs a few minutes each, so plan your submissions. You will learn what the integration grid is, why meta-GGAs are sensitive to it, and how to choose a grid you can trust.

Background

This experiment looks at a subtle issue that can affect the results of any exchange–correlation functional. Kohn–Sham (KS) DFT (Hohenberg and Kohn 1964; Kohn and Sham 1965) needs a real-space grid to evaluate the exchange–correlation integrals. Most programs build it with an algorithm Becke introduced in 1988 (A. D. J. Becke 1988): the integrals become weighted sums over a finite number of points arranged on spheres around each atom. A grid’s “density” is described by its number of radial shells and angular points per shell; (75,302), for example, means 75 radial shells with 302 points each. The choice of grid can change the results significantly, as Wheeler and Houk showed for the M06 family (Wheeler and Houk 2010; Zhao and Truhlar 2008) and Mardirossian and Head-Gordon for two generations of Minnesota functionals (Mardirossian and Head-Gordon 2016b, 2013). They also point out that meta-GGA functionals usually need finer grids than GGAs.

Choosing the grid is often overlooked, and many practitioners are unaware of the issue. Relying on a program’s defaults is not a good idea, even though some programs pick the grid according to the functional (Q-Chem, Inc., n.d.). In this experiment you will study the dissociation curve of the argon dimer. The geometries come from the RG10 subset (Tang and Toennies 2003) of the MGCDB84 database (Mardirossian and Head-Gordon 2017), with the Ar–Ar distance between 3.0 and 6.0 Å. The interaction energy at each distance is

\[ \Delta E(r) = E\big(\mathrm{Ar}_2(r)\big) - 2\,E(\mathrm{Ar}). \]

Use the functionals B3LYP (Vosko et al. 1980; A. D. Becke 1988; Lee et al. 1988; Becke 1993; Stephens et al. 1994), M06-L (Zhao and Truhlar 2006), M11 (Peverati and Truhlar 2011), M11-L (Peverati and Truhlar 2012) and ωB97M-V (Vydrov and Van Voorhis 2010; Mardirossian and Head-Gordon 2016a), and feel free to add others. Use the def2-TZVP basis set (Weigend and Ahlrichs 2005) for all calculations, and try the grids SG-1, SG-2 and SG-3 (Q-Chem keyword XC_GRID = 1, 2 or 3).

Present your results as a dissociation curve like the one in Figure 1, which shows the VSXC functional (Van Voorhis and Scuseria 1998, 2008). Before plotting, collect the data in a table like Table 2.

Run the calculations

This is the largest set of jobs of the course (5 functionals × 3 grids × 32 structures). SG-1 jobs take seconds, but the finer grids cost much more: expect a few minutes per job with SG-2 and SG-3. Work one functional and one grid at a time, and check the first curve before running the rest. Your instructor may split the functionals across the class.

Collect your results with a script

Reading 480 output files by hand is slow, and it’s easy to make mistakes. A small Python script does it for you: ⬇ extract_ex07.py. The same file works on macOS, Windows and Linux.

It reads every Q-Chem output file in a folder, including subfolders. It identifies each job from what Q-Chem echoed in the output (functional, XC_GRID, basis set and Ar–Ar distance), so your file names don’t matter. From each output it takes the total energy, the number of SCF cycles and the wall time, and writes them all to ex07_results.csv in the same folder. It only reads your outputs and never changes them.

Before you start: put all your Experiment 7 output files in one folder. Subfolders, such as one per grid, are fine.

Read the report: don’t skip this step

The script prints a table with the number of usable jobs for each functional and grid. You need 32 in every cell, 480 in total. Then it lists:

  • Missing jobs: run them.
  • Problems: jobs that crashed or hit the 10-minute limit, SCF cycles that didn’t converge, a wrong basis set, or a missing XC_GRID (Q-Chem’s default grid depends on the version and the functional, so it doesn’t count as SG-1, SG-2 or SG-3). The script does not take any energy from these files. Fix the input, rerun the job, and run the script again.
  • Jobs found more than once: the script uses the most recent good run. If it says the energies differ, find out why before you trust either one.
  • Not recognized: other Q-Chem outputs in the folder (for example from another experiment). These are ignored.

You can run the script as often as you like. Each run rereads every output and rewrites the CSV.

WarningUse the script carefully
  • Check its work. Open two or three output files, say one per grid, and compare the total energy, SCF cycles and wall time with the table below (Guide 3 shows where to find them). The script is a tool; the numbers you submit are your responsibility.
  • Don’t edit the CSV and save it from Excel. Depending on your settings, Excel can round the energies or change commas into semicolons. You can look at it in Excel, but close it without saving, and import the file exactly as the script wrote it.
  • Keep your output files. The CSV is a summary, not a replacement for them.

Enter your results

Record the total energy, SCF cycles and wall time of every job. The quickest way is ⬆ Import CSV below: choose ex07_results.csv and all three tabs fill in at once. If any cell already holds a different number, the page asks before replacing it. You can also type the values, or paste a column copied from a spreadsheet. The page computes all interaction energies ΔE(r) = E(Ar₂) − 2 E(Ar) for you and draws the curves as soon as one is complete.
