Lectures

The textbook for the lab: one chapter per class

Study notes for the fifteen classes of the computational lab, from the Schrödinger equation to choosing a method.

Each chapter covers one class in more detail than the lecture can. Read the chapter before (or right after) the class. Each one ends with key points and study questions, and has a printable PDF version under Other Formats.

The first six classes build the theory. Classes 1–3 approximate the wave function (basis sets) and come before Experiment 1. Classes 4–6 approximate the Hamiltonian (Hartree–Fock and density functional theory) and come before Experiment 2. From Class 7 on, each class looks back at the experiment you just finished and prepares the next one.

NoteDebrief sections

From Class 7 on, the first part of each chapter discusses the results of the previous experiment. Read it after you submit that experiment. Your predictions are more useful if they’re your own.
